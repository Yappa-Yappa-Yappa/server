# Security Policy

## Supported Versions

Only the latest version gets security fixes. Older versions are on their own, like a phone that hasn't seen an update since 2019.

| Version | Supported          |
| ------- | ------------------ |
| 5.1.x   | :white_check_mark: |
| 5.0.x   | :x:                |
| 4.0.x   | :white_check_mark: |
| < 4.0   | :x:                |

## Reporting a Vulnerability

Found a bug that could ruin someone's day? Please don't post it in a public issue. Instead, email **[senglysea12@gmail.com]** with the details.

What to expect:

- I'll reply within a few days, usually faster than my coffee gets cold.
- If it's accepted, I'll fix it and credit you (if you want).
- If it's declined, I'll explain why, politely, and won't roast you for it.

Thanks for helping keep the code safe. Hackers hate this one weird trick: responsible disclosure.
